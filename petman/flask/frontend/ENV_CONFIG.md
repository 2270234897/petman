# 环境变量配置说明

## 问题：手机访问看不到真实数据

如果你在手机上访问应用，只看到虚假数据或没有数据，这是因为 API 地址配置问题。

## 快速解决（2分钟）

### 方法 1: 自动配置（推荐）

```bash
cd frontend
node get-ip.js
```

这会自动创建 `.env.local` 文件，配置正确的 API 地址。

### 方法 2: 手动创建

**步骤 1: 查看你的电脑 IP 地址**

Windows:
```bash
ipconfig
```

Mac/Linux:
```bash
ifconfig
```

找到类似 `192.168.x.x` 的地址，例如：`192.168.1.100`

**步骤 2: 在 frontend 目录创建 `.env.local` 文件**

```bash
cd frontend
```

创建 `.env.local` 文件，内容如下：

```env
VITE_API_BASE_URL=http://192.168.1.100:5000
```

⚠️ **重要**: 将 `192.168.1.100` 替换为你的实际 IP 地址！

**步骤 3: 重启开发服务器**

```bash
# 按 Ctrl+C 停止当前服务器
# 然后重新启动
npm run dev
```

## 验证配置

1. **确保后端已启动**:
   ```bash
   cd backend
   python app.py
   ```
   
   应该看到：
   ```
   * Running on http://0.0.0.0:5000
   * Running on http://192.168.1.100:5000
   ```

2. **手机访问测试**:
   - 在手机浏览器访问：`http://你的IP:5173`
   - 首页应该显示真实的统计数据
   - 预约页面应该显示真实的预约记录

3. **检查是否成功**:
   - 数据有加载动画（灰色骨架屏）
   - 统计数字基于真实数据（不是固定的假数据）
   - 浏览器控制台没有网络错误

## 常见问题

### Q: 还是看不到数据？

检查清单：
- [ ] 手机和电脑在同一 WiFi
- [ ] `.env.local` 文件已创建且 IP 地址正确
- [ ] 后端已启动（`python app.py`）
- [ ] 前端已重启（修改 .env 后必须重启）
- [ ] 防火墙没有阻止端口 5000 和 5173

### Q: 桌面浏览器也无法访问了？

使用 IP 地址访问而不是 localhost：
```
http://192.168.1.100:5173
```

### Q: 显示连接错误？

在手机浏览器直接访问后端测试：
```
http://你的IP:5000/api/customers/get
```

如果这个也无法访问，说明：
1. 防火墙阻止了连接
2. 后端没有正确启动
3. 手机和电脑不在同一网络
