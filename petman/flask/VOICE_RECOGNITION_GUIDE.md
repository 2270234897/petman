# 🎙️ AI 语音识别功能使用指南

## 功能概述

AI 智能识别现已支持**语音录入**功能，您可以通过麦克风直接用自然语言描述商品信息，AI 会自动识别并填充到表单中。

---

## 🚀 快速开始

### 1. 打开 AI 智能识别
- 进入：`库存管理` → `商品管理` → `新增商品`
- 点击右上角 **"AI 智能识别"** 按钮（紫蓝色渐变）

### 2. 开始语音录入
1. 在弹窗中找到 **"语音录入"** 部分
2. 点击 **"开始录音"** 按钮（绿色）
3. 允许浏览器访问麦克风（首次使用会提示）
4. 看到红色脉冲图标表示正在录音

### 3. 描述商品信息
用自然语言清晰地描述商品，例如：

> "这是一袋皇家猫粮，500克装的，成猫专用，鸡肉味，保质期18个月"

或者：

> "宠物饮水机，品牌是小佩，智能循环过滤，适合猫狗通用"

### 4. 停止录音
- 点击 **"停止录音"** 按钮（红色）
- 录音会自动保存，显示录音时长

### 5. 开始识别
- 点击 **"开始识别"** 按钮
- AI 会处理语音并提取商品信息
- 识别成功后自动填充到表单

## 💡 使用技巧

### 语音描述建议

#### ✅ 推荐说法
- **清晰描述品牌**："皇家猫粮" / "品牌是皇家"
- **包含规格信息**："500克装" / "1公斤的" / "大号"
- **提及保质期**："保质期18个月" / "保质期一年半"
- **说明适用对象**："成猫专用" / "适合幼犬"
- **描述特点**："鸡肉味" / "智能循环" / "自动加热"

#### ❌ 避免问题
- 不要说得太快，保持正常语速
- 避免环境噪音过大
- 不要离麦克风太远或太近
- 避免使用过于口语化的表达

### 完整描述示例

**示例 1 - 猫粮：**
```
这是一袋皇家猫粮，规格是500克，
适合成猫食用，主要成分是鸡肉，
保质期是18个月，产地法国
```

**示例 2 - 玩具：**
```
这是一个宠物玩具球，品牌是福来恩，
材质是天然橡胶，适合中型犬，
尺寸是直径8厘米
```

**示例 3 - 用品：**
```
这是一台宠物饮水机，小佩品牌的，
容量2升，智能循环过滤系统，
适合猫狗通用，有自动断电保护
```

## 🎯 识别字段

语音识别支持提取以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 商品名称 | 产品名称 | "皇家猫粮" |
| 品牌 | 品牌名称 | "皇家" / "Royal Canin" |
| 规格 | 重量/尺寸/容量 | "500g" / "2L" / "M号" |
| 分类 | 商品类别 | "猫粮" / "玩具" / "用品" |
| 适用动物 | 目标宠物 | "成猫" / "幼犬" / "通用" |
| 保质期 | 以月为单位 | "18个月" → 18 |
| 产地 | 制造地 | "法国" / "中国" |
| 特点 | 产品卖点 | "鸡肉味" / "智能循环" |

## 🔧 技术特性

### 音频格式
- **录制格式**: WebM (Opus编码)
- **采样率**: 16000 Hz
- **声道**: 单声道
- **特性**: 回声消除、噪音抑制

### 处理流程
1. 浏览器录制音频 (MediaRecorder API)
2. 上传到后端服务器
3. Gemini AI 分析语音内容
4. 提取结构化商品信息
5. 返回并填充到表单

### 兼容性
- ✅ Chrome/Edge 89+
- ✅ Firefox 88+
- ✅ Safari 14.1+
- ✅ Opera 75+

- 红色 "停止录音" 按钮

- 绿色勾选图标 ✅

## ⚙️ 配置要求

### 浏览器权限
首次使用需要授权麦克风权限：
1. 浏览器会弹出权限请求
2. 点击 "允许" 
3. 可在浏览器设置中管理权限

### 硬件要求
- 🎤 **麦克风**: 内置或外接麦克风
- 🎧 **耳机麦克风**: 支持（推荐使用以减少噪音）
- 📱 **移动设备**: 支持触控设备的麦克风

### 网络要求
- 科学上网（访问 Gemini API）
- 代理端口配置在 `.env` 文件中

## 🐛 常见问题

### Q: 无法访问麦克风？
**A**: 检查浏览器权限设置
- Chrome: 设置 → 隐私和安全 → 网站设置 → 麦克风
- 确保已允许该网站访问麦克风
- 检查系统麦克风是否正常工作

### Q: 录音没有声音？
**A**: 
- 检查麦克风是否静音
- 确认选择了正确的音频输入设备
- 测试系统麦克风（在系统设置中）

### Q: 识别不准确？
**A**: 
- 说话清晰，语速适中
- 减少环境噪音
- 使用完整句子描述
- 结合图片提高准确度

### Q: 识别超时？
**A**:
- 检查网络连接
- 确认代理正在运行
- 音频文件不要过大（建议30秒内）
