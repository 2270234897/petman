========================================
       手机端连接测试指南
========================================

✅ 服务状态：
   - 后端 (Flask): 运行中 - 端口 5000
   - 前端 (Vite): 运行中 - 端口 5173
   - 配置: VITE_API_BASE_URL=http://192.168.1.11:5000

📱 测试步骤：

1. 在手机浏览器访问测试页面：
   http://192.168.1.11:5173/test-connection.html

2. 测试页面会自动检测：
   ✓ 网络连接状态
   ✓ API 服务器连接
   ✓ CORS 配置
   ✓ 客户数据获取
   ✓ 库存数据获取

3. 如果测试页面能打开但 API 测试失败：
   - 检查防火墙是否阻止了 5000 端口
   - 确认手机和电脑在同一 WiFi
   - 尝试在电脑浏览器访问: http://192.168.1.11:5000/api/customers/get

4. 如果测试页面都无法打开：
   - 确认前端服务正在运行
   - 检查 IP 地址是否正确
   - 尝试 ping 192.168.1.11

🔧 其他测试方法：

直接在手机浏览器访问实际前端：
   http://192.168.1.11:5173

然后打开浏览器控制台（如果支持）查看错误信息

========================================

💡 常见问题：

Q: 测试页面能打开，但 API 连接失败？
A: 很可能是防火墙问题。在 Windows 防火墙中允许端口 5000 入站连接。

Q: 所有测试都成功，但实际前端还是不行？
A: 清除手机浏览器缓存，或使用无痕模式访问。

Q: 手机连不上任何页面？
A: 确认手机和电脑在同一 WiFi，IP 地址是否正确。
