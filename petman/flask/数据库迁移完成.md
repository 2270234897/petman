```powershell

wsl hostname -I

# 修改 backend/db_config.py 中的 host
'host': '172.x.x.x'  # 使用实际IP
```

## 🔍 故障排除

### 常见问题

**Q: 数据库连接失败**
```bash
# 检查MySQL状态
wsl sudo service mysql status

# 重启MySQL
wsl sudo service mysql restart

# 检查绑定地址
wsl cat /etc/mysql/mysql.conf.d/mysqld.cnf | grep bind-address
```

**Q: 端口5000被占用**
```powershell
# 查找进程
netstat -ano | findstr :5000

# 结束进程
taskkill /PID <进程ID> /F
```

**Q: Unicode编码错误**
已在测试脚本中修复，使用 `[OK]` 代替特殊字符。
