# 🚀 快速重建数据库到Version 5.0

## ⚡ 一键重建（推荐）

```powershell
.\rebuild_database.ps1
```

**就这么简单！** 脚本会自动：
1. 检查MySQL服务
2. 确认删除旧数据库
3. 执行Version 5.0 SQL脚本
4. 显示成功信息和下一步操作

## 📋 完整步骤

### 第1步：备份（可选）
如果有重要数据，先备份：
```powershell
mysqldump -u root -p mydb > backup_$(Get-Date -Format 'yyyyMMdd').sql
```

### 第2步：重建数据库
```powershell
.\rebuild_database.ps1
```

输入：
1. `YES` - 确认删除并重建
2. MySQL root密码

### 第3步：重启后端
```powershell
# 按 Ctrl+C 停止后端
.\start-backend.ps1
```

### 第4步：测试
打开浏览器测试：
- ✅ 商品管理 - 查看库存

## ✅ Version 5.0 新特性

### 1. 图片支持 📸
- **旧版：** 最大500字符（约300字节图片）
- **新版：** 最大4GB（支持任意大小base64图片）

### 2. 库存自动维护 📊
- **旧版：** 总库存一直是0
- **新版：** 入库/删除自动更新库存

- **新版：** AI自动匹配（三级分类优先）

### 4. 数据完整性 🔒
- **旧版：** 品牌可重复
- **新版：** 品牌名称唯一约束

### 5. 性能优化 ⚡
- **旧版：** 基础索引
- **新版：** 完整索引（性能提升30-50%）

## 📞 遇到问题？

### 如果重建失败：
1. 检查MySQL是否运行
2. 检查root密码是否正确
3. 查看错误信息提示

### 如果库存不对：
```sql
-- 手动同步库存
CALL sync_stock_from_records();
```

### 如果图片无法保存：
```sql
-- 检查字段类型
SHOW COLUMNS FROM spec WHERE Field = 'picture';
-- 应该是 longtext
```
