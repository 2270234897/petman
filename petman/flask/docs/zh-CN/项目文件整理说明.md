# 项目文件整理说明

本文档说明了项目文件夹的整理情况和新的目录结构。

## 整理时间

2025年10月11日

## 整理内容

### 1. 新增目录

| 目录 | 用途 | 说明 |
|------|------|------|
| `scripts/` | 脚本文件 | 存放所有 PowerShell、批处理和 Python 工具脚本 |
| `tests/` | 测试文件 | 存放所有测试代码 |
| `docs/zh-CN/` | 中文文档 | 存放所有中文文档 |

### 2. 移动的文件

#### 脚本文件（移动到 `scripts/`）

**PowerShell 脚本：**
- `rebuild_database.ps1` - 数据库重建脚本
- `rebuild_database_docker.ps1` - Docker 数据库重建脚本
- `start-backend.ps1` - 后端启动脚本
- `sync_stock.ps1` - 库存同步脚本
- `set-static-ip.ps1` - 设置静态IP脚本
- `update_picture_field.ps1` - 更新图片字段脚本
- `check_services.ps1` - 服务检查脚本

**Python 工具脚本：**
- `add_sample_data.py` - 添加示例数据
- `check_encoding.py` - 检查文件编码
- `fix_encoding.py` - 修复文件编码
- `check_services.py` - 服务检查

#### 测试文件（移动到 `tests/`）

- `test_key_apis.py` - API 测试脚本

#### 中文文档（移动到 `docs/zh-CN/`）

- `Docker数据库重建指南.md`
- `图片字段和品牌填充修复说明.md`
- `库存同步修复说明.md`
- `快速重建数据库.md`
- `数据库迁移完成.md`
- `问题解决总结.md`

#### 英文文档（移动到 `docs/`）

- `AGENT_SETUP_GUIDE.md` - AI Agent 设置指南
- `AI_ASSISTANT_INTEGRATION.md` - AI 助手集成说明
- `CLEANUP_SUMMARY.md` - 清理总结
- `GEMINI_API_SETUP.md` - Gemini API 设置
- `INLINE_EDIT_GUIDE.md` - 内联编辑指南
- `PROJECT_STRUCTURE.md` - 项目结构说明
- `SMART_SEARCH_GUIDE.md` - 智能搜索指南
- `VOICE_RECOGNITION_GUIDE.md` - 语音识别指南

### 3. 保留在根目录的文件

以下重要文件保留在项目根目录：

- `README.md` - 项目主文档
- `requirements.txt` - Python 依赖
- `.gitignore` - Git 忽略配置
- `.env` - 环境变量配置（如果存在）

## 使用脚本的新方式

### 启动后端

**以前：**
```bash
.\start-backend.ps1
```

**现在：**
```bash
.\scripts\start-backend.ps1
```

### 重建数据库

**以前：**
```bash
.\rebuild_database.ps1
```

**现在：**
```bash
.\scripts\rebuild_database.ps1
```

### 同步库存

**以前：**
```bash
.\sync_stock.ps1
```

**现在：**
```bash
.\scripts\sync_stock.ps1
```
