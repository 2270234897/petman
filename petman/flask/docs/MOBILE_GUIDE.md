# 移动端使用指南

## 概述

PetMan 宠物管理系统现已完全支持移动端访问，提供响应式设计和 PWA（渐进式 Web 应用）功能，让您可以在手机、平板等移动设备上流畅使用。

## 主要特性

### 1. 响应式设计
- **自适应布局**：根据设备屏幕尺寸自动调整界面
- **移动端优化导航**：底部导航栏，方便单手操作
- **触摸优化**：所有按钮和交互元素都针对触摸操作优化

### 2. PWA 支持
- **离线访问**：安装后可在无网络时访问已缓存的内容
- **主屏幕图标**：像原生应用一样添加到手机主屏幕
- **推送通知**：支持接收重要通知（需授权）
- **快速启动**：从主屏幕快速启动，无需打开浏览器

### 3. 移动端专属功能
- **下拉刷新**：在列表页面下拉即可刷新数据
- **底部导航**：常用功能快速切换
- **手势操作**：支持滑动、双击等手势
- **触觉反馈**：按钮点击时的触觉反馈

## 安装 PWA 应用

### iOS 设备（iPhone/iPad）

1. 使用 Safari 浏览器访问系统网址
2. 点击底部的"分享"按钮 (□↑)
3. 向下滚动，找到"添加到主屏幕"
4. 点击"添加"确认
5. 应用图标将出现在主屏幕上

### Android 设备

#### 方法一：通过应用内提示
1. 使用 Chrome 或其他现代浏览器访问系统
2. 页面底部会自动弹出"安装应用"提示
3. 点击"立即安装"
4. 应用将添加到主屏幕

#### 方法二：手动添加
1. 使用 Chrome 浏览器访问系统网址
2. 点击右上角菜单 (⋮)
3. 选择"添加到主屏幕"或"安装应用"
4. 点击"安装"确认

### 主界面布局

#### 顶部导航栏
- **菜单按钮**：左上角，打开侧边栏查看更多功能
- **搜索按钮**：快速搜索功能
- **通知按钮**：查看系统通知

#### 底部导航栏
- **首页** 🏠：系统仪表盘
- **预约** 📅：预约管理
- **客户** 👥：客户管理
- **库存** 📦：库存管理
- **助手** ✨：AI 智能助手

### 移动端专用组件

#### 1. 移动卡片（Mobile Card）
展示信息的卡片式布局，适合移动端阅读

#### 2. 浮动操作按钮（FAB）
屏幕右下角的圆形按钮，用于主要操作（如"添加"）

#### 3. 下拉刷新
在列表顶部下拉可刷新数据

#### 4. 侧边抽屉
从左侧滑出的菜单，包含所有功能入口

## 移动端优化功能

### 性能优化
- **代码分割**：按需加载，减少初始加载时间
- **图片懒加载**：滚动到可视区域才加载图片
- **离线缓存**：常用资源离线可用
- **预加载**：智能预加载可能访问的页面

### 用户体验优化
- **触摸反馈**：点击时有视觉和触觉反馈
- **防误触**：按钮最小触摸区域 44x44px
- **自适应字体**：根据系统设置调整字体大小
- **暗色模式**：支持系统暗色模式（如果设备支持）

### 网络优化
- **离线检测**：自动检测网络状态
- **后台同步**：网络恢复后自动同步数据
- **压缩传输**：减少数据传输量

## 移动端最佳实践

### 对于用户

1. **首次使用**
   - 建议安装为 PWA 应用，获得最佳体验
   - 允许通知权限，及时接收重要信息
   - 在 WiFi 环境下首次加载，缓存更多内容

2. **日常使用**
   - 使用底部导航栏快速切换功能
   - 下拉刷新获取最新数据
   - 使用搜索功能快速查找信息

3. **离线使用**
   - 已查看过的内容可离线访问
   - 离线时做的修改会在网络恢复后自动同步
   - 关键功能离线可用

### 对于开发者

1. **测试移动端**
   ```bash
   # 启动开发服务器，允许网络访问
   cd frontend
   npm run dev
   
   # 在手机浏览器中访问
   http://你的电脑IP:5173
   ```

2. **调试移动端**
   - Chrome DevTools 的移动设备模拟器
   - Safari 的响应式设计模式
   - 真机调试（推荐）

3. **构建部署**
   ```bash
   # 构建生产版本
   cd frontend
   npm run build
   
   # 构建产物在 dist/ 目录
   # Service Worker 和 manifest 会自动包含
   ```

## 常见问题

### 1. 如何更新应用？
- **已安装 PWA**：应用会自动检查更新，提示刷新即可
- **浏览器访问**：刷新页面获取最新版本

### 2. 离线功能有限制吗？
- 已浏览的页面可离线访问
- 图片和静态资源会缓存
- API 请求需要网络连接（部分支持离线）

### 3. 占用多少存储空间？
- 基础应用：约 2-5MB
- 缓存数据：根据使用情况增长，最多 50MB
- 可在浏览器设置中清除缓存

### 4. 如何卸载 PWA？
- **iOS**：长按图标 → 删除
- **Android**：长按图标 → 卸载

### 5. 移动端性能慢？
- 检查网络连接
- 清除浏览器缓存
- 重新安装 PWA
- 确保系统和浏览器是最新版本

## 反馈与支持

如果您在使用移动端时遇到问题：

1. 检查浏览器控制台错误信息
2. 尝试清除缓存并刷新
3. 更新到最新版本
4. 提交问题到项目仓库
