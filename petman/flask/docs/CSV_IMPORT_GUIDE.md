# CSV商品导入功能使用指南

## 功能概述

我已经为你的宠物管理系统创建了一个完整的CSV商品导入功能，可以将门店导出的商品数据批量导入到系统中。

## 主要功能

### 1. CSV数据转换器 (`src/lib/csv-converter.ts`)
- 解析门店导出的CSV文件格式
- 自动提取品牌、分类、规格等信息
- 处理商品属性和保质期信息
- 生成导入报告和统计信息

### 2. CSV文件处理器 (`src/lib/csv-processor.ts`)
- 智能解析CSV文件（处理引号、逗号等特殊字符）
- 数据质量验证
- 生成详细的统计报告

### 3. CSV导入界面 (`src/components/inventory/csv-import.tsx`)
- 用户友好的文件上传界面
- 实时数据预览和验证
- 自动创建缺失的品牌和分类
- 批量导入进度显示

## 使用方法

### 1. 访问导入页面
- 在系统中导航到 "库存管理" -> "导入"
- 你会看到新的"CSV商品导入"模块

### 2. 上传CSV文件
- 点击"选择文件"按钮
- 选择你的CSV文件（如：`门店导出商品-导出结果 -猫狗日记-2025-09-21.csv`）
- 系统会自动解析和验证数据

### 3. 查看导入报告
系统会显示：
- 总行数和有效商品数量
- 发现的品牌和分类
- 数据质量警告和错误
- 数据预览（前10条）

### 4. 执行导入
- 确认数据无误后，点击"开始导入"
- 系统会自动：
  - 创建缺失的品牌
  - 创建缺失的分类
  - 按商品名称分组并创建商品
  - 显示导入进度

## 数据映射

### CSV字段映射到系统字段
| CSV字段 | 系统字段 | 说明 |
|---------|----------|------|
| 商品名称 | product_name | 商品名称 |
| 商品条形码 | barcode | 条形码 |
| 售价 | price | 销售价格 |
| 活动价 | sale_price | 活动价格（可选） |
| 库存 | 总库存 | 库存数量 |
| 重量 | weight | 商品重量 |
| 商品状态 | status | 上架状态 |
| 类目属性 | attributes | 商品属性信息 |

### 自动提取的信息
- **品牌**：从"类目属性"字段中提取"品牌：xxx"信息
- **分类**：使用"商品三级类目"、"商品二级类目"、"商品一级类目"
- **产地**：从"类目属性"中提取"是否进口"信息
- **保质期**：从"类目属性"中提取"保质期：xx个月"信息

## 支持的CSV格式

系统支持你提供的CSV格式，包含以下字段：
- 商品ID, 规格, 商品条形码, 商品名称
- 商品一级类目, 商品二级类目, 商品三级类目
- 重量, 售价, 活动价, 库存
- 商品状态, 类目属性
- 以及其他相关字段

## 错误处理

### 数据验证
系统会检查：
- 必填字段（商品名称、售价、库存）
- 数据格式（价格和库存必须是数字）
- 数据完整性

### 常见问题解决
1. **品牌信息缺失**：系统会尝试从商品名称中提取品牌
2. **分类信息不完整**：使用可用的分类级别
3. **重复商品**：按商品名称分组，合并不同规格

## 导入结果

导入完成后，系统会显示：
- 成功导入的商品数量
- 失败的商品数量
- 自动创建的品牌和分类数量

## 技术实现

### 核心文件
- `src/lib/csv-converter.ts` - 数据转换逻辑
- `src/lib/csv-processor.ts` - 文件处理逻辑
- `src/components/inventory/csv-import.tsx` - 用户界面
- `src/pages/inventory/import.tsx` - 导入页面

### API集成
- 使用现有的品牌、分类、商品创建API
- 自动处理数据关联和ID映射
- 支持批量操作和错误恢复

## 注意事项

1. **数据备份**：建议在导入前备份现有数据
2. **分批导入**：如果数据量很大，建议分批导入
3. **数据检查**：导入后检查数据完整性
4. **权限控制**：确保有足够的权限创建品牌、分类和商品
