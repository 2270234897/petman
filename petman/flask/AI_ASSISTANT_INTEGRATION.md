# AI 智能识别功能集成说明

## 📋 功能概述

AI 智能识别功能已完全集成到商品管理系统中，无需单独页面，直接在新增商品表单中使用。

---

## 🎯 使用流程

### 1. 打开新增商品页面
访问：`库存管理` → `商品管理` → `新增商品`

### 2. 点击 "AI 智能识别" 按钮
位置：表单右上角的渐变色按钮（紫蓝色）

### 3. 在弹窗中输入信息
可以选择以下任一方式或组合使用：
- **上传商品图片**：支持 JPG、PNG、WEBP 格式
- **输入文字描述**：例如 "皇家猫粮500g，适合成猫，鸡肉味"

### 4. 点击 "开始识别"
- AI 将在 10-30 秒内完成识别
- 识别过程中显示加载动画

### 5. 自动填充表单
识别成功后：
- ✅ 商品名称自动填充
- ✅ 品牌自动匹配（如果存在于系统中）
- ✅ 分类自动匹配（如果存在于系统中）
- ✅ 保质期自动填充
- ✅ 规格自动预填
- ✅ 条形码自动填充
- ✅ 库存数量默认填充
- ✅ 产地、产品详情自动填充

### 6. 检查并补充信息
- 查看 AI 填充的信息是否正确
- 如果品牌或分类未找到，会显示警告提示，需要手动选择
- 选择规格类型（重量、尺寸、颜色等）
- 补充其他必填字段

### 7. 保存商品
点击 "创建商品" 完成添加

---

## 🔧 AI 识别的字段映射

| AI 识别字段 | 表单字段 | 说明 |
|-----------|---------|------|
| product_name | 商品名称 | 直接填充 |
| brand | 品牌 | 智能匹配系统品牌 |
| category | 分类 | 智能匹配系统分类 |
| specification | 规格值 | 预填到规格表 |
| shelf_life | 保质期 | 直接填充（月数） |
| origin | 产地 | 直接填充 |
| features | 商品详情 | 直接填充 |
| barcode | 条形码 | 预填到规格表 |
| quantity | 库存 | 预填到规格表（默认1） |

## 💡 使用技巧

### 提高识别准确度
1. **清晰的图片**：确保图片清晰，商品信息可见
2. **正面拍摄**：尽量使用商品正面图，包含品牌和规格信息
3. **补充文字**：如果图片信息不全，添加文字描述
4. **多图片**：支持上传多张图片，提供更多信息

### 品牌匹配
- 如果 AI 识别的品牌在系统中存在，会自动选中
- 如果未找到，会显示警告："品牌 'xxx' 未在系统中找到，请手动选择"
- 需要手动从下拉列表选择正确的品牌

### 分类匹配
- 类似品牌，会自动匹配系统中的分类
- 未匹配到会提示手动选择

### 规格处理
- AI 识别的规格会预填充到规格表的 "规格值" 字段
- 仍需手动选择 "规格类型"（如：重量、尺寸等）
- 条形码和库存会一同预填充

## ⚙️ 配置要求

### 必需配置
1. **Gemini API Key**：在 `.env` 文件中配置
   ```env
   GEMINI_API_KEY=你的API密钥
   ```

2. **代理设置**（如需科学上网）：
   ```env
   PROXY_PORT=7890
   ```

3. **后端运行**：确保 Flask 后端正在运行
   ```bash
   python backend/app.py
   ```

4. **前端运行**：确保前端开发服务器正在运行
   ```bash
   cd frontend
   npm run dev
   ```

## 🔍 故障排查

### 问题：点击 "AI 智能识别" 无反应
**解决**：检查浏览器控制台是否有错误，确认前端已重新编译

### 问题：识别超时
**解决**：
1. 检查网络连接
2. 确认代理是否运行（如需科学上网）
3. 检查后端日志是否有错误

### 问题：品牌/分类未匹配
**解决**：
这是正常情况，手动从下拉列表选择即可。建议：
- 在系统中预先添加常用品牌
- 完善分类体系

### 问题：识别结果不准确
**解决**：
1. 使用更清晰的图片
2. 添加文字描述辅助识别
3. 识别后手动修正

## 📊 最佳实践

### 1. 批量录入
对于同品牌、同系列商品：
- 第一个商品使用 AI 识别
- 后续商品复制并修改规格即可

### 2. 信息完整性
AI 识别后务必检查：
- ✓ 品牌是否正确
- ✓ 分类是否准确
- ✓ 规格信息是否完整
- ✓ 保质期是否正确

### 3. 规格管理
- 先选择规格类型
- 再填写规格值
- 确保条形码唯一性（如有）
