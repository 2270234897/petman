# 图片识别商品信息功能

## 🎯 功能概述

为宠物管理系统添加了基于图片识别的商品信息自动提取功能，用户可以通过上传商品图片自动识别并提取商品信息，大大提高商品录入效率。

## ✨ 主要特性

### 🔍 智能识别
- **OCR文字识别**: 使用 Tesseract.js 引擎，支持中英文识别
- **智能解析**: 自动识别商品名称、品牌、条形码、规格、价格等信息
- **多格式支持**: 支持 JPG、PNG、GIF、BMP、WebP 等图片格式

### 🎨 用户体验
- **拖拽上传**: 支持拖拽上传图片文件
- **实时预览**: 上传后立即显示图片预览
- **进度指示**: 显示识别进度和状态
- **结果展示**: 清晰展示识别结果，支持手动编辑

### 🔧 集成方式
- **表单集成**: 在商品表单中一键打开图片识别功能
- **独立页面**: 提供独立的图片识别页面
- **自动填充**: 识别结果自动填充到商品表单中

## 🚀 使用方法

### 1. 在商品表单中使用

1. 进入 **库存管理** → **商品管理**
2. 点击 **新增商品** 或 **编辑商品**
3. 在商品表单页面，点击右上角的 **图片识别** 按钮
4. 上传商品图片
5. 点击 **开始识别** 按钮
6. 系统会自动识别图片中的文字信息
7. 点击 **应用到商品表单** 将识别结果填充到表单中

### 2. 独立使用图片识别功能

1. 在侧边栏点击 **图片识别**
2. 上传商品图片
3. 点击 **开始识别** 按钮
4. 查看识别结果
5. 可以复制识别到的原始文本

## 📊 识别规则

### 商品名称识别
- 查找标题位置的长文本
- 排除纯数字和价格信息
- 优先选择前几行的有效文本

### 品牌信息识别
- 关键词匹配: "品牌", "Brand", "厂家"
- 智能文本提取
- 与现有品牌库匹配

### 条形码识别
- 正则表达式: `\b\d{8,13}\b`
- 8-13位数字匹配
- 优先选择最长的数字串

### 价格信息识别
- 正则表达式: `[￥¥$]\s*\d+(?:\.\d{2})?`
- 支持多种货币符号
- 自动格式化价格

## 🎯 使用建议

### 图片质量要求
- 使用清晰、光线充足的图片
- 确保图片中的文字清晰可读
- 建议图片大小不超过 10MB
- 尽量保持图片水平，避免倾斜

### 识别准确率优化
- 使用高分辨率图片
- 确保文字与背景对比度足够
- 避免图片模糊或抖动
- 尽量使用正面拍摄的商品图片

1. **识别失败**: 检查图片是否清晰，尝试重新上传
