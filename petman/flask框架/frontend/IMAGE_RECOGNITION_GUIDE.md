# 图片识别商品信息功能使用指南

## 功能概述

本功能允许用户通过上传商品图片，自动识别并提取商品信息，包括：
- 商品名称
- 品牌信息
- 条形码
- 规格信息
- 价格信息
- 商品描述

## 使用方法

### 1. 在商品表单中使用

1. 进入 **库存管理** → **商品管理**
2. 点击 **新增商品** 或 **编辑商品**
3. 在商品表单页面，点击右上角的 **图片识别** 按钮
4. 上传商品图片
5. 点击 **开始识别** 按钮
6. 系统会自动识别图片中的文字信息
7. 点击 **应用到商品表单** 将识别结果填充到表单中

### 2. 独立使用图片识别功能

1. 在侧边栏点击 **图片识别**
2. 上传商品图片
3. 点击 **开始识别** 按钮
4. 查看识别结果
5. 可以复制识别到的原始文本

## 技术特性

- **OCR引擎**: 使用 Tesseract.js 进行文字识别
- **多语言支持**: 支持中文和英文识别
- **智能解析**: 自动解析商品名称、品牌、条形码等信息
- **拖拽上传**: 支持拖拽上传图片文件
- **实时预览**: 上传后立即显示图片预览

## 支持的图片格式

- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- BMP (.bmp)
- WebP (.webp)

## 使用建议

1. **图片质量**: 使用清晰、光线充足的图片
2. **文字清晰**: 确保图片中的文字清晰可读
3. **图片大小**: 建议图片大小不超过 10MB
4. **角度**: 尽量保持图片水平，避免倾斜
5. **内容完整**: 确保商品标签或包装上的信息完整可见

## 识别准确率优化

- 使用高分辨率图片
- 确保文字与背景对比度足够
- 避免图片模糊或抖动
- 尽量使用正面拍摄的商品图片

## 注意事项

- 识别结果仅供参考，建议人工核对
- 复杂背景可能影响识别准确率
- 手写文字识别准确率相对较低
- 建议在识别后检查并修正信息

## 故障排除

### 识别失败
- 检查图片是否清晰
- 尝试重新上传图片
- 确保图片格式正确

### 识别结果不准确
- 尝试调整图片角度
- 使用更高分辨率的图片
- 手动修正识别结果

### 页面加载缓慢
- 首次使用需要下载OCR模型，请耐心等待
- 确保网络连接稳定
