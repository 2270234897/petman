# 图片识别商品信息功能演示

## 🎬 功能演示步骤

### 步骤1: 启动应用
```bash
npm run dev
```
访问 http://localhost:5173

### 步骤2: 进入图片识别功能

#### 方式一：通过商品表单
1. 点击侧边栏 **库存管理**
2. 点击 **商品管理**
3. 点击 **新增商品** 按钮
4. 在商品表单页面，点击右上角的 **图片识别** 按钮

#### 方式二：直接访问独立页面
1. 点击侧边栏 **图片识别**

### 步骤3: 上传商品图片
1. 准备一张包含商品信息的图片（如商品包装、标签等）
2. 将图片拖拽到上传区域，或点击选择文件
3. 系统会显示图片预览

### 步骤4: 开始识别
1. 点击 **开始识别** 按钮
2. 系统会显示识别进度
3. 识别完成后会显示结果

### 步骤5: 查看识别结果
系统会自动识别并显示：
- 商品名称
- 品牌信息
- 条形码
- 规格信息
- 价格信息
- 描述信息
- 原始识别文本

### 步骤6: 应用识别结果
1. 检查识别结果是否准确
2. 点击 **应用到商品表单** 按钮
3. 系统会自动填充到商品表单中
4. 继续完善其他信息并保存

## 🔧 高级功能

### 1. 品牌智能匹配
- 系统会尝试将识别到的品牌与现有品牌库匹配
- 如果找到匹配的品牌，会自动选择
- 如果没有匹配，会显示识别到的品牌名称供参考

### 2. 规格信息处理
- 自动解析规格信息
- 支持多个规格同时识别
- 自动添加到规格列表中

### 3. 条形码处理
- 自动识别8-13位数字条形码
- 自动填充到规格的条形码字段
- 支持多种条形码格式

## 🚨 注意事项

### 1. 图片质量要求
- 确保图片清晰，文字可读
- 避免模糊、倾斜的图片
- 确保光线充足
- 建议使用正面拍摄的图片

### 2. 识别准确率
- 印刷体文字识别准确率较高
- 手写文字识别准确率较低
- 复杂背景可能影响识别效果
- 建议在识别后人工核对结果

### 3. 性能考虑
- 首次使用需要下载OCR模型，请耐心等待
- 大图片处理时间较长
- 建议图片大小不超过10MB

## 🎉 使用技巧

### 1. 提高识别准确率
- 使用高分辨率图片
- 确保文字与背景对比度足够
- 避免图片模糊或抖动
- 尽量使用正面拍摄的商品图片

### 2. 优化识别结果
- 识别后检查结果准确性
- 手动修正不准确的信息
- 利用原始文本进行二次确认

### 3. 提高录入效率
- 批量处理相似商品
- 利用识别结果快速录入
- 结合手动输入完善信息
